# Доработки Maschine Mikro MK3

Один патч для **Maschine 3.7.1 x64 / Windows / Mikro MK3**. Установка сразу на поддерживаемый оригинальный EXE; предыдущие версии патча не нужны.

[История изменений](CHANGELOG.md) и [планы развития](CHANGELOG.md#future-development).

1. Закрой Maschine и DAW, если в ней открыт плагин Maschine.
2. Запусти **Install.cmd**, подтверди права администратора.
3. Дождись зелёного сообщения об установке и открой Maschine.

**Check.cmd** — проверить установку. **Restore.cmd** — вернуть оригинал.
Резервная копия хранится рядом с EXE; не удаляй её.

В Browse: стрелки переключают типы файлов, Shift+стрелки — продукты.
Колесо листает результаты, Shift+вращение сохраняет быструю прокрутку.
Shift+нажатие добавляет FX в конец цепочки или меняет источник с сохранением FX
для Instrument, One-shot и Loop. Для целого Sound отдельной операции нет.

Нажатие колеса **без Shift** оставляет штатную загрузку NI и не гарантирует
очистку FX. На переустановленной Maschine без патча подтверждено: если первым
плагином многослотового Sound стоит Sampler, загрузка One-shot меняет сэмпл
в первом слоте и сохраняет эффекты. При замене другого источника, например
Bass Synth, результат может отличаться. Это относится и к загрузке мышкой.
**Shift + нажатие** — наша явная команда сохранения FX, в том числе при замене
других типов источников.

В PLUG-IN: вращение колеса на верхнем уровне выбирает слот. Экран и управление
параметрами штатные. Erase+нажатие удаляет выбранную составляющую.

Python не нужен. Пакет не содержит EXE Maschine или исходных скриптов NI:
нужный код извлекается и изменяется из установленного приложения.
Неизвестные сборки и чужие модификации отклоняются. Официальная подпись
изменённого EXE теряет действительность. Обновления Maschine требуют
повторной проверки совместимости.

Подробности и установка в нестандартную папку: [README.md](README.md).
