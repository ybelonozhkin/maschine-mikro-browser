# 0.2.0 — 2026-10-11

You can now answer the save prompt from the Mikro. Turn the encoder to choose Cancel, Discard or Save, then press and release it. The prompt starts on Cancel, and the browser behind it stays inactive.

Removing a plug-in now requires **Shift + Erase + encoder click**.

Install directly on the supported original Maschine 3.7.1 x64, or upgrade from a listed previous patch with its matching original backup. Restore.cmd puts back the original EXE.

Windows filename dialogs and missing-library/sample relocation still require the computer.

Installation, checking, repeated installation, restore, upgrades and rejection of invalid files/backups passed the local tests. Lua tests cover save-prompt controls and the removal shortcut. The assembled release was also checked on a physical Mikro MK3.
